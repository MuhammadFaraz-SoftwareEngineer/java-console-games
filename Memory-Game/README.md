# Memory Game
A Java console-based memory matching game where players flip cards to find matching pairs within limited attempts.

## Project Versions

### Basic Version

Built using:
- Primitive Arrays
- Manual Shuffle Logic
- Core Java Fundamentals

### Advanced Version

Built using Java built-in utilities:
- ArrayList
- Collections.shuffle()
- Arrays.fill()
- Improved Game State Handling

## Features
- Card matching gameplay
- Randomized card positions
- Input validation
- Limited attempts system
- Win/Lose conditions

## Concepts Used
- Java
- Arrays
- ArrayList
- Collections Framework
- Loops & Conditional Statements
- Methods
- Scanner Class

## How To Run
1. Open project in VS Code or IntelliJ IDEA
2. Open either BasicVersion or AdvancedVersion
3. Compile the Java file
4. Run MemoryGame.java
