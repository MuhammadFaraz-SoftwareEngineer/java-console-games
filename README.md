# Java Console Projects
This repository contains multiple Java console-based games developed using Core Java concepts.

## Projects Included

### 1. Number Guessing Game
A console-based game to guess a random number.

### 2. Memory Game
This is a console-based memory matching game where players flip two cards per turn to find matching pairs hidden on the board.

### 3. Tic Tac Toe
This Java program is a console-based 3×3 Tic-Tac-Toe game for two players, where players take turns placing X and O on the board.

## Concepts Used
- Java
- Arrays and Collections
- Loops and Conditional Statements
- Methods and Console-Based Interface
