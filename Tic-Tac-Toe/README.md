# Tic Tac Toe
A Java console-based 3x3 Tic Tac Toe game featuring multiple gameplay versions, ranging from a simple two-player mode to an advanced AI opponent using the Minimax Algorithm.

## Project Versions

### Two-Player Version

Built using:
- Arrays
- Core Java Fundamentals
- Conditional Statements
- Loops & Methods

Features:
- Player vs Player gameplay
- Input validation
- Winner detection
- Draw detection

### Medium AI Version

Built using:
- Arrays
- Decision-Based AI Logic
- Conditional Statements
- Methods

Features:
- Player vs Computer gameplay
- AI blocks player winning moves
- AI prioritizes winning moves
- Smart move selection using:
  - Center priority
  - Corner priority
  - Side selection
- Input validation
- Winner & draw detection

### Harder AI Version

Built using:
- Arrays
- Recursion
- Minimax Algorithm
- Advanced Decision-Making Logic

Features:
- Unbeatable AI opponent
- Optimal move calculation
- Recursive Minimax implementation
- Player vs Computer gameplay
- Winner & draw detection
- Input validation

## Concepts Used
- Java
- Arrays
- Recursion
- Minimax Algorithm
- Loops & Conditional Statements
- Methods
- Scanner Class

## How To Run
1. Open project in VS Code or IntelliJ IDEA
2. Open any version folder:
   - Two-Player-Version
   - Medium-AI-Version
   - Minimax-AI-Version
3. Compile the Java file
4. Run TicTacToe.java
